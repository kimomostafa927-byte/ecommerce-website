# NORTHLINE — E-Commerce Website

A modern, responsive e-commerce front-end project built using HTML, CSS, and JavaScript.

## Overview
NORTHLINE is a fictional online store designed to demonstrate front-end development skills and interactive e-commerce functionality.

## Features
- Responsive website layout.
- Product search functionality.
- Interactive shopping cart.
- Add and remove products.
- Quantity management.
- Automatic price calculation.
- Cart persistence using Local Storage.
- Checkout form and order confirmation.

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser Local Storage
- GitHub Pages

## Live Demo
https://kimomostafa927-byte.github.io/ecommerce-website/

## Installation
1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Explore the website and its features.

## Project Limitations
This is a front-end demonstration project. It does not include a real payment gateway, backend server, or database.
